# SakuraTTS 0.1.0a1 开发者预览版

本版提供 Windows / NVIDIA 日文推理的 Python 安装包和源码。GitHub 保存源码，ModelScope 提供维护者手动构建的开发者 ZIP；普通推理使用自有 CUDA GPT 和独立 ORT 声学工作进程，不导入 PyTorch。

ZIP 包含 wheel、源码 tar.gz、安装说明、Windows 主环境固定依赖和 SHA256 清单。源码包保留模型转换、参考准备、产品测试及维护工具；研究工具和证据从对应 Git 提交获取；wheel 只安装产品代码和许可。构建版本、源码 commit、源码与产物哈希见包内 `release-manifest.json`。

下载后先核对 ZIP 旁 `.sha256` 文件，再阅读 `QUICKSTART.md`。此包不包含 Python、CUDA/cuDNN、模型、参考音频或字典。需要自行准备独立声学组件和资源，安装 wheel 本身不会下载模型或直接产生语音。当前声学组件准备工具需要本地已有的官方运行文件，具体步骤在源码包的 `docs/setup-windows-nvidia.md`。

当前实测为 Windows x64 / Python 3.11、RTX 5060 8 GB 和 Sakura V2ProPlus。CuPy / NVRTC 头文件所在的 Python 环境路径需只含 ASCII 字符，建议使用 `D:/SakuraTTS/`；日文文本和模型参考名称不受这项安装限制影响。支持日文、单活动请求、完整 WAV；默认 FP32 对照路径保留，低显存和速度候选通过显式参数选择。预览版不宣称其他模型或 GPU 已通过验收。

自然生成的速度配置完成 25.90 秒 PCM 的热请求中位数为 1557.08 ms，全卡采样峰值增量为 1108 MiB；低显存配置生成 25.46 秒 PCM 为 2373.28 ms，全卡增量为 799 MiB。计时和资源采样分别运行，增量包含桌面负载且可能漏采短峰值。两组输出长度不同，数字不能组合为同一配置，也不代表流式首包或进程独占显存。

声学 FP16 尚不满足原官方 FP32 的严格波形容差。24 条音频已有辅助 ASR 检查，部分内容疑点和人工听感仍待验；源码中保留各项失败与证据。尚不提供中文整链、量化、并发服务、流式播放或 Sakura 宿主集成。`doctor --nvidia --config` 暂只检查原 FP32 整图包，FP16 分块候选须实际合成验证。

项目自身采用 MIT。第三方代码与资源的原始许可随包保留，角色模型、参考音频和 NVIDIA 运行库不自动适用本项目许可。

本地打包验证结果由源码中的 `research/experiments/2026-09-20-windows-preview.md` 单独记录。上传时应选择已验收的具体 ZIP 和 `.sha256`，不要上传 `models/`、`.venv`、`outputs/` 或开发机器的完整环境。
