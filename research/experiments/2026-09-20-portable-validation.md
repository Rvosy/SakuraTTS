日期：2026-09-20（Asia/Shanghai）。本轮增加离线导出、纯 NumPy 校验与比较入口，以及 Mac 执行适配器。目的是让 Windows 候选使用现有官方输入和阈值重放，尚未执行 Windows / CUDA。

## 来源与范围

原始结果保留在参考目录。本轮证据根目录：

`SakuraTTS-References/runs/20260919T161243.721246Z-portable-validation-suite`

`run_suite.py` 保存完整参数和复现调用，`processes.json` 保存每个进程的真实退出码。导出源为 `20260919T125743.942661Z-official-mps` 的真实 GPT 采样，以及 `20260919T122232.246358Z-sovits-fixed-official-mps` 的固定声学条件。两者的目标 semantic、phones、参考谱与 speaker embedding 在导出时逐数组核对；后者的原始来源文件也按历史哈希复查。

四例为 `ja-reported-intro`、`ja-short`、`ja-long`、`ja-punctuation`，原文不变。模型仍是固定官方提交 `48b1a0169a28582a8984402f82cf438d3bfa6aca` 的“朱雀院红叶”V2Pro。模型归档作为外部资源按 SHA-256 绑定，不复制进数据包。

数组原始载荷 28,033,876 字节（26.73 MiB）；含 NPZ、manifest 与来源快照的 63 个文件共 30,931,399 字节（约 29.50 MiB）。这是逻辑文件体积，不是安装包或运行内存。bundle manifest SHA-256 为 `4ed592a1386a9c8aaf6986116e7ab07bc586eb64ccf5db62816ed12ebee6a8c8`。

数据格式、布局转换、比较范围与命令见 [Windows 接续验收](../../docs/windows-validation.md)。历史上没有记录的官方文件身份继续标为未知；不能把导出时的源码或资源哈希补成历史运行证据。

## 实际验证

导出、改名目录中的校验、两次候选执行均退出 0。两次比较均退出 1，状态为 `numerical_mismatch`，对应已有差异。

| 检查 | 默认 FP32 encoder | 显式 FP64 softmax 累积 |
|---|---|---|
| 固定历史 GPT logits | 四例共 731 步通过 | 同左 |
| 自行生成 token、history、semantic、返回索引和停止原因 | 四例全部相同 | 同左 |
| 自行生成 logits | 731 步通过 | 同左 |
| 采样概率 | 长句第 274 步 `[0,857]` 一个值超差 | 同一失败 |
| 12 个声学计算阶段 × 四例 | 47/48 通过；标点 MRTE `[0,21,125]` 超差 | 48/48 通过 |
| 自行生成的最终波形 | 四例通过原容差 | 四例通过原容差 |

概率仍用 `atol=1e-6, rtol=1e-5`；logits、声学阶段和波形仍用 `atol=1e-4, rtol=1e-5`。已知失败不豁免，也未切换默认声学精度。

`verify_isolated.py` 禁止导入 MLX、Torch、Transformers、`resource`，并限制所有文件打开只能发生在搬迁后的 `relocated/日文検証` 下。实际校验退出 0，打开的 63 个文件全部在该目录中。此时未提供模型目录，结果明确为 `external_models_not_checked`；另一次有外部权重参数的校验已核对两个模型包。

11 项局部测试通过，覆盖文件与数组损坏、缺输出、参数 / 模型 / bundle 身份不符、非有限数值、目录搬迁、原阈值失败和生成历史分歧。独立审查还发现并修正一个报告问题：自行生成 semantic 不同时，其波形不再冒充同输入数值比较，固定 semantic 的声学对照仍正常执行。

`review.py` 的独立离线复核退出 0，结果保存在 `review.json`：1,554 个包数组通过身份检查，13 个执行源码与当前工作树对应；原包和搬迁副本文件逐字节相同。复核没有运行模型。

## 结论边界

这次没有修改推理计算，也不宣布速度或内存改善。候选运行含逐步捕获和 CPU 数组复制，记录的资源数据只属于诊断进程，不能与正常请求速度、CUDA 显存或流式首包比较。

未做新的 ASR 或人工试听。数据包不执行原始文本前端与参考准备；它用于后端数值验收，不能代替 Windows 的完整日文请求验收。下一项处理已复现的默认文本编码问题，保持原包字节和模型行为不变。
