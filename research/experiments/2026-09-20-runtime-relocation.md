# 日文运行目录的独立部署验证

日期：2026-09-20。本轮检查普通日文入口能否脱离旧 checkout、虚拟环境、原模型目录和历史实验运行，并将基础解释器纳入文件体积。

## 导出方式

新增 `research/tools/export_japanese_runtime.py`，只用标准库复制显式输入。运行源码保留 `scripts/src` 结构，GPT、SoVITS、日文前端和参考包放入 `resources/`；保留完整 site-packages、distribution 元数据、词典与 Nani 资源。仅忽略字节码缓存和 `.DS_Store`，没有删减模型、语言资源或推理功能。

旧虚拟环境的解释器链接、`pyvenv.cfg` 和脚本包含绝对路径，不能直接复制后改名。本轮默认复制基础 CPython，再用它在最终输出位置创建 `venv --without-pip`，最后复制依赖。内部符号链接映射到新目录，指向被复制树外的链接拒绝；每个普通文件在复制后和最终清点时都核对哈希。

默认 `bundled` 检查基础解释器和新环境的运行路径都位于新目录。`external` 仅作为明确保留外部解释器的实验选项，本轮结果不覆盖它。CPython 的构建配置仍可含旧前缀，运行路径与构建元数据分开记录，不能据此声称扩展编译和嵌入式 Python 也可搬迁。

导出清单只表示文件已复制和核验，不执行模型、不提供隔离合成结论。新 venv 仍绑定最终安装位置，之后移动目录需要重建；它也依赖 macOS 系统库和 Apple arm64 的 MLX 轮子，不能作为 Windows 安装包。

## 完整请求对照

在旧环境为四条原始日文分别运行 NumPy seed 0 基线，再从新目录用相同参数生成。新进程由 `/usr/bin/sandbox-exec` 启动，禁止访问旧 checkout、旧虚拟环境和基础 Python、原模型目录、整个历史 `runs/`、官方 / Lite 源码及网络。仅为子进程将 HOME、TMPDIR 和 XDG_CACHE_HOME 指向新目录；不修改用户环境。

实际负探针验证八个旧文件的读取和网络访问均报权限拒绝。四个旧环境 CLI 与四个隔离 CLI 全部退出 0，stderr 均为空。原文、规范化、音素和分段、生成计数与停止摘要、参数与精度策略、四包身份、依赖 / 词典及源码哈希相同，四份 PCM 和完整 WAV 逐字节相同；源码记录包括此前补齐的 `gpt_prefill.py`，未导入 Torch、Transformers 或中文前端。

随后发现初轮没有禁用 `getconf` 返回的 Darwin 用户 cache / temp 目录：它们不受 HOME 重定向控制。新增严格 profile，禁止这两个规范化路径，分别用本轮专属目录中的 34-byte sentinel 验证读取被拒，再补跑四例。四例均退出 0，与同一基线的上述比较全部相同，新增负探针及四个 CLI 的 stderr 也为空。初轮记录未改写，两组隔离证据分别保存；总计执行 12 个实际 CLI 进程。

本轮只比较部署前后的当前运行时，使用自由采样 seed 0。CLI 未保存完整 token 序列，因此生成摘要相同不等于逐 token 数值验收。既有概率和 MRTE 数值失败未因此消除，也没有新增 ASR 或人工试听。

首次隔离报告句的请求耗时为 4.923 s，旧环境同例为 1.640 s；其余三例隔离请求为 1.066、3.999、2.198 s。这些是各一次新进程运行，含首次运行和沙箱影响，没有定位首例耗时来源，也未用于性能收益结论。隔离检查通过只说明依赖与输出，不说明启动速度已达标。

严格 cache 隔离的四例耗时为 2.423、1.802、4.615、2.866 s，也保留为该条件下的观察。没有据此宣称缓存带来某个固定加速倍数；后续生产后端仍需单独测量冷启动、重复启动和系统缓存成本。
