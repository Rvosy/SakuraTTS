# 自有 MLX GPT 转换与 Metal 数值验证

日期：2026-09-19。这是 Apple M4 上的 GPT 单模块候选实现，尚未接入文本前端、采样和 SoVITS，不是完整 TTS 引擎，也没有替代桌宠原有 CPU TTS。

## 实现

`src/sakuratts/_internal/conversion/convert_gpt.py` 使用 PyTorch 读取原始官方 GPT checkpoint，校验真实结构和全部权重，生成独立 FP32 NPZ、配置与来源清单。转换不覆盖原文件；不识别的权重、形状或结构直接报错。当前只验证了“朱雀院红叶”V2Pro 配套 GPT，不宣称支持整个家族。

`src/sakuratts/backends/mlx/gpt.py` 自己实现模型加载、Prefill 和单 token Decode，使用 MLX 的矩阵乘法、注意力和 LayerNorm。文本双向可见、音频因果可见，位置编码、post-norm、ReLU 与官方固定提交对应。运行过程不导入 Lite 或官方推理代码。

位置编码在转换时按官方 CPU FP32 公式保存，运行时乘原始 alpha。这让首轮对照集中在执行图，而不把不同 sin 实现混进误差。原始 FP16 存储权重转为与现有 MPS 基线相同的 FP32；这不是低精度优化。

独立环境 `../SakuraTTS-References/.venv-mlx-macos` 只有 MLX 0.32.2、mlx-metal 0.32.2、NumPy 2.4.6 等必要 Python 安装工具，没有安装 PyTorch。候选依赖固定在 `requirements/mlx-candidate.txt`。转换器仍独立依赖 PyTorch。

## 实际数值验证

先用小模型把缓存 Decode 与独立 NumPy FP64 的完整前缀计算比较，最大绝对误差约 1.02e-7。再在 Metal 上使用相同官方音素、BERT、参考 token 和完整固定生成历史：

| 样例 | Prefill + Decode 步数 | 最大绝对误差 | RMS | Top-1 一致 |
|---|---:|---:|---:|---:|
| 日文用户回归 | 121 | 2.861e-5 | 6.302e-6 | 121 / 121 |
| 中文用户回归 | 147 | 2.909e-5 | 6.408e-6 | 147 / 147 |

全部 logits 满足运行前代码中固定的 `abs(error) <= 1e-4 + 1e-5 * abs(reference)`，没有按结果放宽。该检查只说明这两组输入上的计算误差；自由采样、内容、音色、其他精度与模型尚未验证。后续扩展语料继续使用相同容差。

证据（相对于参考目录）：

- 转换包：`models/converted/20260919T104221.749176Z-010197bfc30b-gpt-fp32/`。
- Metal 逐步 logits 与差值：`runs/20260919T104245.269578Z-mlx-gpt-gpu/`。
- 从修正后的源码快照直接执行 CPU 自检：`runs/20260919T104809.990049Z-mlx-gpt-self-test-cpu/`。

## 资源和限制

GPT 包的 FP32 权重归档为 318,699,510 字节，大于原 FP16 checkpoint 的 155,313,376 字节。当前证明了 GPT 运行依赖分离，没有证明完整安装体积下降。

该进程的 MLX active 加载后约 318.65 MB，执行后约 419.32 MB，分配器 peak 为 594,938,532 字节；释放模型并清缓存后 active / cache 均为 0。这里使用十进制 MB，原始字节保存在结果中。这些是 GPT 单模块的 MLX 分配器计数，不能与完整 TTS 的 PyTorch MPS driver、进程 RSS 或 NVIDIA 显存混比。

KV 当前有固定逻辑容量，使用 `slice_update`。尚未证明底层一定原位更新，也没有声称消除了整段复制。下一步单独测量容量、分配与正常计算时间，再决定是否需要专门算子。逐步 CPU 拷贝的诊断时间不作为加速证据。

官方源码与 MLX 使用 MIT 许可，转换包保留了官方许可。角色权重的再分发许可尚未确定，产物仅保存在本机参考目录。

## 复现

在项目根目录，使用已准备好的模型与环境：

```sh
REF=/Users/beyondpower/Documents/Projects/SakuraTTS-References
"$REF/.venv-macos/bin/python" src/sakuratts/_internal/conversion/convert_gpt.py --references "$REF" --checkpoint "$REF/models/suzakuinmomiji/voice/models/朱雀院红叶-e15.ckpt"
# package 使用上一条命令实际返回的新目录。
"$REF/.venv-mlx-macos/bin/python" research/tools/mlx_gpt_replay.py --references "$REF" --package "$REF/models/converted/20260919T104221.749176Z-010197bfc30b-gpt-fp32" --official-run "$REF/runs/20260919T102853.549769Z-official-mps" --device gpu
"$REF/.venv-mlx-macos/bin/python" research/tools/mlx_gpt_replay.py --references "$REF" --self-test
```

当前选择 MLX 进行可在 Mac 上实际验证的算子实验。CUDA 后端仍待 NVIDIA 实机，尚未确定最终生产后端；不为这些候选增加通用多后端框架。
