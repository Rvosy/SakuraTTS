## 命令行、音素和识别结果

`sakuratts convert --reference-language zh` 从原始权重和普通话转写生成模型目录，再以 `sakuratts tts --language zh` 依次在 CPU、CUDA 合成“你好，欢迎使用樱花语音。今天是星期五，出门记得带伞。”两份输出都是 6.06 秒、32 kHz 的单声道 WAV。

同一输入在原版 GPT-SoVITS 与 SakuraTTS 中的规范化文本、49 个音素和逐字对齐全部一致，BERT 特征最大绝对差为 0.000021。“樱花语音”的四个读音为 yīng、huā、yǔ、yīn。本地 Paraformer-large 将两份 WAV 和原版 CPU 的对照录音均转写为整句原文。Whisper-large-v3-turbo 对两份 SakuraTTS 录音均将“樱花语音”转写为“樱花云”，对原版录音转写为“樱花语音”。这组结果记录文本和自动识别情况，未进行人工听感评分。

用“银行的 Windows 电脑正在运行。”检查中英混读。中文前端将“银行”读为 yínháng，将“运行”读为 yùnxíng，英文前端为 Windows 生成六个音素。合并后的特征矩阵为 1024 × 25，中文段保留 BERT 特征，英文段的六列按 V2 约定填零。

## 日英包解压验收

从日英压缩包重新解压，核对清单内的 20,821 个文件。用本地 Sakura V2ProPlus 权重和日文参考录音启动 CPU 服务。日文“おはよう。今日もよろしくね。”生成 3.42 秒音频，英文“Good morning. Have a nice day.”生成 3.26 秒音频。日文从空缓存开始，覆盖首次转换、参考准备、重复请求、服务重启和 direct 模式。英文复用已转换模型及日文参考，managed 和 direct 两种模式均通过。日英包的清单中没有普通话模型或词表。

本地 Whisper 无提示识别与日文输入一致。英文首词 Good 被识别为 One，后半句“Have a nice day”与输入一致。
